# BMS (Business Meeting System) - 회의관리 앱

휴대폰과 PC 브라우저에서 쓰는 회의관리 웹앱(PWA)입니다. 홈 화면에 설치하면 앱처럼 쓸 수 있습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 회의 일정 관리 | 월간 캘린더에서 회의를 등록하고 수정합니다. 회의는 파란 점, 할 일 마감은 주황 점으로 표시됩니다. |
| 캘린더 연동 | **구글 캘린더에 추가** 버튼, 또는 **.ics 파일**로 휴대폰 기본 캘린더·구글·아웃룩에 등록합니다. 회의 시작 전 알림이 함께 들어갑니다. |
| 회의 녹음 | **녹음 시작**을 누르면 회의 내용 메모장만 전체 화면으로 뜹니다("회의 메모" 제목과 "회의정보 보기" 버튼만 표시, 녹음 표시 없음). "회의정보 보기"를 누르면 녹음과 메모가 저장되고 회의 화면으로 돌아갑니다. 화면이 꺼지지 않고, 메모는 15초마다 자동 저장됩니다. 갤럭시 음성 녹음 앱의 파일도 **녹음 파일 불러오기**로 붙일 수 있습니다. |
| 회의 내용 텍스트 저장 | 녹음 중 메모한 내용이 회의 내용으로 저장됩니다. 음성 녹음 앱의 텍스트 변환 결과를 붙여 넣거나 .txt 파일로 불러올 수도 있습니다. |
| 녹음 → 텍스트 변환 | **🎧 녹음 파일 → 텍스트 변환**(또는 녹음 목록의 **텍스트 변환**)을 누르면 휴대폰 안에서 Whisper 음성 인식으로 한국어 텍스트를 만들어 회의 내용에 `[분:초]`와 함께 넣습니다. API 키가 필요 없고 내용이 밖으로 나가지 않습니다. 모델은 처음 한 번 내려받습니다(정확 약 300MB / 빠름 약 150MB, 설정에서 선택). |
| 회의 상태 | 회의 화면 아래 **회의 종료 / 회의 취소 / 회의 삭제** 버튼. 종료·취소된 회의는 알림이 울리지 않고 목록에 표시됩니다. 다시 누르면 되돌릴 수 있습니다. |
| 회의록 작성 | 갤럭시 **음성 녹음** 앱의 Galaxy AI 요약을 붙여 넣거나 **공유 → BMS**로 바로 보냅니다(API 키 필요 없음). 회의록은 복사하거나 .md 파일로 받을 수 있습니다. |
| 할 일 → 일정 등록 | **할 일 자동 찾기**가 회의록에서 할 일, 담당자(예: 이과장), 마감일(예: "다음 주 금요일까지")을 찾아 줍니다. 각 할 일의 📅 버튼이나 .ics 파일로 캘린더에 넣으면 마감일 오전 9시에 알림이 옵니다. |
| 다음 회의 알람 | **다음 회의 잡기**로 같은 그룹의 다음 회의를 만들면, 끝나지 않은 할 일이 그 회의 화면에 표시됩니다. 회의 시작 N분 전에는 할 일 목록과 함께 알림이 옵니다. |

## 갤럭시 폰에서 쓰는 순서 (API 키 없이)

1. BMS에서 **+ 새 회의**로 회의를 등록하고, 구글 캘린더나 .ics로 휴대폰 캘린더에도 넣습니다.
2. 회의 때 갤럭시 **음성 녹음** 앱으로 녹음합니다.
3. 녹음 파일을 열고 **텍스트 변환 → 요약**(Galaxy AI)을 누릅니다.
4. 요약 화면에서 **공유 → BMS**를 누르고, 저장할 회의와 '회의록'을 고릅니다. 공유 목록에 BMS가 없으면 **복사**한 뒤 BMS 회의록 칸의 **붙여넣기**를 누릅니다.
5. **할 일 자동 찾기**를 눌러 할 일을 확인하고 등록합니다.
6. **다음 회의 잡기**로 다음 회의를 만들면, 끝나지 않은 할 일이 그 회의에 넘어가고 회의 전에 알림이 옵니다.

> 공유 목록에 BMS가 나오려면 크롬에서 BMS를 연 뒤 메뉴(⋮) → **홈 화면에 추가(앱 설치)**를 해야 합니다.

## 휴대폰에서 열 수 있게 올리기 (GitHub Pages, 무료)

서버 없이 `public` 폴더만으로 동작합니다. 저장소에 GitHub Pages 배포 설정(`.github/workflows/deploy-bms.yml`)이 들어 있습니다.

1. GitHub 저장소 → **Settings → Pages**로 갑니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions** 탭 → **Deploy BMS to GitHub Pages** → **Run workflow**를 누릅니다.
4. 1~2분 뒤 `https://autocratna-cell.github.io/Miracom/` 에서 열립니다.

## (선택) 서버 + Claude AI 요약으로 실행

API 키가 있으면 서버를 띄워서 'AI 요약' 버튼도 쓸 수 있습니다. 서버가 없거나 키가 없으면 이 버튼은 자동으로 숨겨집니다. Node.js 20 이상이 필요합니다.

```bash
cd BMS
npm install
ANTHROPIC_API_KEY=발급받은키 npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다.

- `ANTHROPIC_API_KEY`: AI 요약에 필요합니다. https://console.anthropic.com 에서 발급합니다. 키가 없어도 AI 요약을 뺀 나머지 기능은 모두 동작합니다.
- `PORT`: 서버 포트입니다(기본 3000).
- `BMS_MODEL`: 요약에 쓸 Claude 모델입니다(기본 `claude-opus-5-5`).

### 휴대폰에서 쓰기

- 마이크와 알림은 **HTTPS 주소**(또는 localhost)에서만 동작합니다. 사내 서버나 클라우드(Render, Railway, Fly.io 등)에 HTTPS로 올려서 쓰세요.
- 크롬에서 연 뒤 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 설치됩니다.

## 알아둘 점

- **데이터 저장 위치**: 회의, 할 일, 녹음은 사용하는 기기의 브라우저(IndexedDB)에만 저장됩니다. 다른 기기와 공유되지 않으니 **설정 → 백업 파일 받기**로 백업하세요. 녹음 파일은 백업에 포함되지 않습니다.
- **앱 알림**: 앱(또는 탭)이 열려 있을 때 울립니다. 휴대폰이 잠겨 있어도 확실히 받으려면 .ics로 휴대폰 캘린더에 등록하세요. 캘린더 일정 설명에 지난 할 일 목록이 들어가고 알림도 설정됩니다.
- **녹음**: 안드로이드는 마이크를 한 앱만 쓸 수 있어, 갤럭시 음성 녹음 앱과 BMS 녹음을 동시에 할 수는 없습니다. 둘 중 하나만 쓰세요.
- **Galaxy AI 요약**: 처리는 갤럭시 폰에서 합니다. 할 일 자동 찾기는 문장 규칙으로 동작하므로, 등록 전에 내용을 확인하고 필요하면 항목을 눌러 고쳐 주세요.
- **(선택) 서버 AI 요약**: 회의 텍스트가 Anthropic API로 전송됩니다. 사내 보안 정책을 확인하세요.

## 폴더 구조

```
BMS/
├── server.js               # 웹 서버 + AI 요약 API (/api/summarize)
├── package.json
├── .env.example            # 환경변수 예시
└── public/                 # 웹앱 화면
    ├── index.html
    ├── styles.css
    ├── manifest.json, sw.js, icon.svg   # 앱 설치(PWA)용
    └── js/
        ├── app.js              # 화면 동작
        ├── db.js               # 기기 저장소(IndexedDB)
        ├── recorder.js         # 회의 녹음
        ├── tasks.js            # 회의록에서 할 일·담당자·마감일 찾기
        ├── stt.js, stt-worker.js # 녹음 → 텍스트 변환 (Whisper, transformers.js)
        └── calendar-export.js  # 구글 캘린더 링크, .ics 생성
```
